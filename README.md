# 🔺 تطبيق آفاق - مثلثيات PRO 
> **مشروع تعليمي تفاعلي لمادة الرياضيات - الصف العاشر**

تطبيق ذكي صُمم لتسهيل فهم الاقترانات المثلثية (Trigonometry) والزوايا، مع واجهة مستخدم حديثة تدعم الرؤية الليلية (Dark Mode).

## ✨ مميزات التطبيق
- **رسوم بيانية حية:** تمثيل دقيق للاقترانات باستخدام مكتبة Chart.js.
- **واجهة مستخدم متطورة:** تصميم "Future-Tech" بأسلوب عصري.
- **أدوات حسابية:** إيجاد النسب المثلثية للزوايا بسهولة.

## 🛠 التقنيات المستخدمة
- **HTML5 & CSS3** (تصميم متجاوب بالكامل).
- **JavaScript** (لمنطق العمليات والرسوم).
- **GitHub Pages** (للاستضافة السحابية).
